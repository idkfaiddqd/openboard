# Граница агрегата через MCP

`aggregate-boundary` хранит утверждение автора диаграммы о границе агрегата и известных ссылках на UML-классы. Это не проверка доменной модели, транзакций или инвариантов. Расположение класса внутри или вне рамки само по себе не меняет членство, а UML-композиция не создаёт его автоматически.

```json
{"board_id":"BOARD_ID","shapes":[
  {"id":"aggregate","type":"aggregate-boundary","x":40,"y":40,"w":800,"h":400,"name":"Order","rootId":"order","memberIds":["line"]},
  {"id":"order","type":"uml-class","x":100,"y":140,"name":"Order","attributes":[],"operations":["confirm()"],"role":"Entity"},
  {"id":"line","type":"uml-class","x":500,"y":140,"name":"OrderLine","attributes":[],"operations":[]}
]}
```

У границы обязательны `x`, `y` и непустое имя; крайние пробелы имени удаляются. Размер по умолчанию — 440×300, заданные размеры должны быть положительными. `rootId` необязателен; `memberIds` — массив известных дополнительных членов, по умолчанию пустой. Пустой список не утверждает, что других членов нет; отсутствие root означает только, что он не указан. Каждая ссылка должна указывать на отдельный UML-класс той же доски, а не интерфейс; корень не повторяется среди дополнительных членов. ID новых классов можно указывать до их определения в том же пакете.

`get_canvas_state` возвращает ID границы и её явные ссылки. Пустая строка в `rootId` очищает корень, пустой `memberIds` — известные дополнительные ссылки. Роль класса — отдельный текст; отображаемая отметка `«Aggregate Root»` определяется ссылкой и не перезаписывает роль. Удаление границы сохраняет классы. Удаление класса через MCP или локально в браузере очищает относящиеся к нему ссылки, сохраняя другие классы и границу.

Повреждённые ссылки, которые уже присутствуют в документе, не удаляются молча и не блокируют несвязанные операции; их можно явно исправить или очистить. Прямой PATCH произвольного документа не гарантирует целостности всех ссылок. Сценарий предполагает последовательную работу: дождитесь `Saved` до обновления страницы или следующей правки. Одновременные несохранённые изменения, SVG и автоматическая проверка доменных инвариантов вне этого среза.

В браузере внутренность рамки не перехватывает обычный выбор классов; саму границу можно выбрать за край. Удаление и восстановление проверялись вручную на отдельной доске, включая ожидание `Saved`; автоматического браузерного теста этого сценария пока нет.
